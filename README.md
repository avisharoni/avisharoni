# Avi Sharoni

Finance and FP&A professional (Babson BS, NYU Stern MBA) with a background in real estate and audit. I now work on AI response evaluation and task authoring, and I build small, tested Python research tools.

All repos are small, self-contained, MIT-licensed, and have tests and CI. Data is synthetic or generated by the code, and every benchmark number in a README was measured by running that repo's script.

### Finance, audit & quant
| Repo | What it is |
